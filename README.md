# Mesto

## Уровень 1. Проектирование
Для создания микрофронтендов выбран фреймворк Module Federation. Single SPA делает упор на разнообразие фреймворков,
что нам не нужно в случае Mesto, так как вполне достаточно React для всех нужд приложения. Также, у Module Federation
есть механизм использования общих библиотек, что упростит переиспользования компонентов между разными микрофронтендами, 
в отличии от Single SPA.

## Уровень 2. Планирование изменений
Монолит был разбит на следующие микрофронтенды:
- auth -> содержит в себе компоненты по аутентификации/регистрации пользователя на сайте
- gallery -> содержит компоненты по просмотру и иному взаимодействию с галереей
- profile -> содержит компоненты по просмотру/редактированию профиля пользователя
- host -> является хостом и агрегирует в себе компоненты из удаленных модулей, которые определены выше

Структура нашего приложения такая:
``
/auth
    /src
        /components
            InfoTooltip.js  // Компонент для вывода информации после отправки формы регистрации
            Login.js        // Компонент входа пользователя
            Register.js     // Компонент регистрации пользователя
        /styles
            auth-form.css   // Стили для форм входа и регистрации пользователя
        /utils
            auth.js         // Утилиты для аутентификации
        index.js            // Точка входа микрофронтенда
    package.json            // Зависимости и скрипты микрофронтенда
    webpack.config.js       // Конфигурация модуля для сборщика
/gallery
    /src
        /components
            AddPlacePopup.js// Popup-компонент для добваления новой картинки
            Card.js         // Компонент для вывода картинки с информацией о ней и хендлерами: лайкнуть, удалить
            ImagePopup.js   // Popup-компонент с картинкой 
        /styles
            card.css        // Стили для карточек с картинками
        /utils
            gallery.js      // Утилиты для галереи
        index.js            // Точка входа микрофронтенда
    package.json            // Зависимости и скрипты микрофронтенда
    webpack.config.js       // Конфигурация модуля для сборщика
/host
    /src
        /components
            Footer.js                // Компонент для подвала сайта
            Header.js                // Компонент для шапки сайта
            Main.js                  // Компонент с основным контентом сайта: информация о пользователе, галерея
            ProtectedRoute.js        // Компонент для проверки авторизации клиента
        /contexts
            CurrentUserContext.js   // Контекст пользователя в приложении
        /images                     // Изображения приложения
        /styles
            /blocks
                /content            // Стиль основного блока приложения, где выводится информация и галерея пользователя
                /places             // Стили по отрисовке списка карточек с картинками
                /popup              // Стили popup'ов проекта
            /footer                 // Стили подвала сайта
            /header                 // Стили шапки сайта
            /page                   // Стили разных элементов приложения
        /utils
            profile.js              // Утилита для работы с бэкендом приложения
        /vendor                     // Папка со шрифтами и стилизацией их в приложении
        App.jsx                     // Основной компонент для сбора всех остальных компонентов приложения
        index.js                    // Точка входа микрофронтенда
    package.json                    // Зависимости и скрипты микрофронтенда
    webpack.config.js               // Конфигурация модуля для сборщика, а также указание удаленных модулей для импорта компонентов
/profile
    /src
        /components
            EditAvatarPopup.js      // Popup-компонент редактирования аватарки
            EditProfilePopup.js     // Popup-компонент редактирования профиля
            PopupWithForm.js        // Popup-компонент для отображения вышеуказанных форм
        /styles
            profile.css             // Стили для компонентов профиля
        /utils
            profile.js              // Утилиты для работы с профилем
        index.js            // Точка входа микрофронтенда
    package.json            // Зависимости и скрипты микрофронтенда
    webpack.config.js       // Конфигурация модуля для сборщика
``
